# 病斑分类模型改进是否源于真实病斑特征：归因遮挡与因果干预实验方案

## 1. 研究问题与核心逻辑

当前 improved model 相较 baseline 的分类准确率提高，但提升的来源尚不明确：模型可能更好地利用了病斑形态、纹理和颜色，也可能更依赖背景、拍摄设备、光照、水印等与标签偶然相关的线索。

本实验围绕以下问题展开：**改进模型的性能提升，是否伴随着对病斑区域更明确的定位、对病斑信息的实质依赖，以及对非病斑因素更低的敏感性？**

证据链：

> 性能确实提高 → 归因区域与病斑相符 → 删除这些区域会影响预测 → 删除真实病斑比删除匹配的非病斑更有影响 → 保留病斑、改变背景时预测相对稳定 → 在独立来源数据上仍然成立。

这里的“反向证明”应表述为**通过受控干预检验病斑依赖假设**。仅凭热图或 Top-k 遮挡后的性能下降，不能证明模型排除了所有伪相关，更不能证明病理学意义上的因果机制。

## 2. 与现有实验的衔接

根据当前目录已有研究材料，可以沿用靶斑病与健康叶片的分类任务，并将现有圆形、方形病斑遮挡实验扩展为归因驱动、真实病斑驱动和非病斑对照三类干预。具体模型结构和最新数据规模以实际实验记录为准。

- 已有圆形／方形遮挡用于检验遮挡形状的影响，但两者需匹配实际遮挡面积与病斑覆盖率。
- 新增 LRP、Grad-CAM、LIME，用于回答“模型认为哪里重要”。
- 人工病斑标注用于回答“重要区域是否真的是病斑”，不能用模型热图替代独立标注。
- 背景替换及跨来源测试用于检验数据集伪相关。

## 3. 可检验假设

| 假设 | 检验方式 | 支持该假设的结果 |
|---|---|---|
| H1：改进模型具有更高分类性能 | 原始独立测试集、跨来源测试集 | Macro-F1、Balanced Accuracy 等提升，且报告置信区间 |
| H2：改进模型的归因更集中于病斑 | 热图与人工病斑掩膜比较 | 面积校正后的病斑富集程度提高 |
| H3：模型确实依赖高归因区域 | Top-k 删除与等面积对照 | 高归因删除引起更大的目标类别得分下降 |
| H4：这种依赖来自病斑而非背景 | 独立病斑删除、健康组织删除、背景删除 | 病斑删除的影响大于匹配对照；背景影响较小 |
| H5：改进模型降低了伪相关依赖 | 固定病斑的背景／来源变化 | 改进模型预测更稳定，跨来源性能更稳健 |

H3 成立而 H2、H4 不成立，可能说明模型忠实地依赖了伪相关区域。真实病斑依赖与背景依赖也可能同时存在。

## 4. 数据与比较原则

### 4.1 模型与数据划分

1. 比较 baseline 与 improved model，尽量使用相同训练数据、划分、预处理和训练预算；记录无法对齐的设置。
2. 建议至少 3 个、条件允许时 5 个训练随机种子；解释方法随机种子与训练种子分别记录。
3. 按植株、叶片、拍摄批次或来源分组划分，避免同一对象的相似照片跨训练／测试集泄漏。
4. 使用验证集确定 Top-k 比例、归因参数和主要终点；最终测试集不用于挑选最好看的配置。
5. 保留跨地块、设备、季节或数据来源的外部测试集；若没有，明确说明泛化证据有限。

### 4.2 最低标注需求

- 每张图像：类别、来源／拍摄批次及可用的对象编号。
- 干预评估子集：独立人工病斑掩膜；建议增加叶片掩膜，以区分病斑、健康叶片组织、叶外背景。
- 标注者尽量不查看模型热图；记录病斑边界不确定区，必要时用掩膜腐蚀／膨胀做敏感性分析。
- 若只能标注部分数据，应按类别、来源和病斑大小分层抽样，并明确结论适用于该子集。

病斑删除实验以患病图像为主要分析对象，健康图像作为假干预对照。完整分类指标则另在全部测试样本上报告，避免混淆两个分析总体。

## 5. LRP、Grad-CAM 与 LIME 的统一设置

三种方法分别提供相关性分解、梯度定位和局部扰动近似的解释，输出尺度并不相同，不能直接把原始数值混合或比较。[LRP 工具论文](https://www.jmlr.org/beta/papers/v17/15-618.html)、[Grad-CAM 原论文](https://openaccess.thecvf.com/content_ICCV_2017/papers/Selvaraju_Grad-CAM_Visual_Explanations_ICCV_2017_paper.pdf)、[LIME 原论文](https://www.kdd.org/kdd2016/papers/files/rfp0573-ribeiroA.pdf)。

### 5.1 解释目标

- 主分析固定为真实类别得分；靶斑病二分类的患病子集固定解释“靶斑病”得分。
- 可另做原始预测类别解释，但必须单独标注，且遮挡后不能更换解释目标。
- LRP 记录传播规则、目标层及稳定参数；Grad-CAM 记录卷积层、上采样方式；LIME 记录超像素算法、分段数、扰动样本数、替换值和种子。
- 错分样本保留在主分析中，另报告两模型均预测正确的公共子集；后者不能替代完整结果。

### 5.2 Top-k 的定义

定义 q 为遮挡面积占候选区域面积的比例，建议 q ∈ {0, 1%, 5%, 10%, 20%, 30%, 50%}。主候选区域为整幅有效图像；另以叶片内区域作为补充实验，不能混用分母。

1. 对原图一次性生成热图，并固定排序，按 q 累积删除；动态重新解释作为单独扩展实验。
2. LRP 和 LIME 的主分析仅使用正贡献；负贡献单独报告，不对绝对值排序后称为“正贡献”。正贡献面积不足时记录实际面积，不用零值或负值区域悄悄补齐。
3. LIME 以超像素为解释单位，应报告累积超像素后的实际面积及预算偏差。随机、低贡献等对照匹配实际面积。
4. Grad-CAM 的粗分辨率热图上采样后并不等于获得像素级定位精度。
5. 为降低粒度差异的影响，可增加统一 patch／共同超像素实验：按单元内平均正归因排序，以面积累计，并报告实际面积。原生粒度与统一粒度的结果分别呈现。
6. 同一区域的 RGB 通道一起替换，防止通道级操作产生不自然颜色。

## 6. 干预矩阵：把解释忠实性与病斑依赖分开

| 组别 | 操作 | 主要回答的问题 |
|---|---|---|
| A 原图 | 无编辑 | 原始性能与得分 |
| B Top-k | 删除最高正贡献区域 | 高归因区域是否影响预测 |
| C Random-k | 等面积随机删除，多次抽样 | 影响是否超出一般信息破坏 |
| D Bottom-k | 删除低贡献区域，匹配实际面积 | 归因排序是否有效 |
| E Lesion | 删除人工标注病斑或其预设比例 | 模型是否依赖真实病斑 |
| F Healthy-leaf | 删除健康叶片组织 | 病斑影响是否具有区域特异性 |
| G Background | 删除叶外背景 | 模型是否依赖背景 |
| H Keep-lesion | 保留病斑及必要上下文，替换其余区域 | 病斑是否提供较充分的分类信息 |
| I Background-swap | 病斑及叶片保持不变，替换背景 | 背景变化是否导致预测漂移 |
| J Sham-edit | 同样编辑流程但尽量保持原内容 | 编辑工具与边界本身的影响 |

E、F、G 的部分区域删除应匹配面积、尽可能匹配形状／连通性；候选区域不足时统一缩小预算或标记缺失，不能重复遮挡凑面积。完整病斑删除另行报告，因为完整病斑面积因图像而异。

另拆分 Top-k ∩ 病斑 与 Top-k ∩ 非病斑，分别统计归因占比和匹配面积下的删除效应，直接判断高贡献区域的影响来自哪里。

### 6.1 避免两个模型用不同掩膜导致比较不公平

使用两类结果：

- **各自热图、各自掩膜**：检验每个模型解释的忠实性。两者效应差异同时包含模型差异与掩膜差异。
- **共享掩膜、两模型共同评估**：优先使用人工病斑和匹配背景掩膜；补充将 baseline 生成、improved 生成的掩膜分别交叉施加到两个模型。该设计更适合比较模型依赖差异。

### 6.2 替换方式与分布偏移

黑块可能使图像偏离训练分布，因此“准确率下降”可能同时包含信息删除与遮挡伪影的影响。ROAR 提出移除后重训练，正是为了处理单纯删除评估中的这一混淆。[ROAR 原论文](https://papers.neurips.cc/paper_files/paper/2019/file/fe4b8556000d0f0cae99daa5c5c5a410-Paper.pdf)。

建议至少使用两种机制不同的替换方式：固定值遮挡作为参考；局部健康纹理替换或修复作为主要补充。模糊可能保留形状，修复也可能引入新纹理或重新生成病斑，均需要人工质量检查。

- 每种替换方式使用相同的区域掩膜和统一参数。
- 随机修复可生成多次，先在同一样本内平均，再跨样本统计。
- 检查是否残留病斑、误改病斑外组织或产生明显接缝；预设排除标准并报告排除数。
- 背景替换使用多个、类别平衡的供体背景，供体与目标标签独立分配，避免制造新的标签关联。
- ROAR 作为可选补充，需对训练、验证和测试实施一致的删除规则并重训练；它评估剩余信息的可学习性，不等同于原始固定模型的干预效应。

## 7. do 算子与 ATE：明确干预对象和结论边界

### 7.1 两个层次的干预

设疾病状态 D 影响病斑特征 L，拍摄环境 E 影响背景／成像特征 B；观测图像 X 由 L、B 及其他叶片特征共同生成，模型输出为 S=fθ(X)。数据收集或样本筛选可能使 D 与 E 在数据集中相关。

**像素编辑干预**可写成 do(X_R ← b)，即把区域 R 替换为规则 b 产生的内容，并保持模型参数固定。这能够直接评估指定编辑对模型输出的影响。

更强的**语义病斑干预** do(L=0) 要求编辑确实移除病斑，同时保持其他因素尽量不变。普通 mask 不自动满足这一条件。因此本文首先估计“图像编辑策略对模型输出的平均效应”，只有在编辑有效、区域外基本不变等假设得到支持时，才谨慎解释为病斑信息的效应。

真实类别标签在这里是评估分层依据，模型得分是结果变量；不是在估计“删除图像病斑会使植株的真实疾病消失”。

### 7.2 处理、潜在结果与符号

对固定模型 m、解释方法 a、预算 q 和替换方式 b，定义：

- T=0：原始图像；T=1：按指定区域策略实施删除。
- Sᵢ,m(0)=p_m(cᵢ | xᵢ)，Sᵢ,m(1)=p_m(cᵢ | xᵢ^edited)。
- cᵢ 为预先固定的目标类别，两种状态使用相同类别。

标准“处理减对照”的样本平均处理效应为：

$$
\widehat{ATE}^{score}_{m,a,q,b}=\frac{1}{N}\sum_i[S_{i,m}(1)-S_{i,m}(0)].
$$

删除支持性信息通常使该值为负。为便于阅读，同时定义正向的**删除损失**：

$$
DL_{m,a,q,b}=-\widehat{ATE}^{score}_{m,a,q,b}.
$$

DL 越大，表示该编辑引起的目标类别概率下降越多。它不是“因果性越强”的通用分数。

这是有限测试样本上的配对平均编辑效应；若要推广到目标总体，需要测试样本具有代表性。由于可以对同一输入分别运行原图与编辑图，无需通过观察性处理组／对照组匹配来补齐模型输出，但编辑的语义有效性仍需验证。

不同模型概率尺度与饱和程度可能不同，跨模型比较不能仅依赖概率 ATE。辅以目标 logit 或类别 margin 的模型内变化、正确性变化和校准结果；原始 logit 的尺度也不宜直接跨模型解释为依赖强弱。

### 7.3 任务指标与 ATE 的区别

定义 Cᵢ,m(t)=1[argmax f_m(xᵢ(t))=yᵢ]，则在同一评估样本集上：

$$
\widehat{ATE}^{correct}_m=\frac1N\sum_i[C_{i,m}(1)-C_{i,m}(0)]
=Accuracy_{edited}-Accuracy_{original}.
$$

F1 和 AUROC 是样本集合上的非线性指标，其编辑前后差值应称为 ΔF1、ΔAUROC，不能直接称为逐样本 ATE。

患病子集病斑删除的概率效应与全测试集准确率效应必须注明各自分母。固定原始标签评估病斑删除图时，衡量的是模型响应；不能把删除后准确率越高理解为模型一定越好，因为语义证据已被改变。

### 7.4 更贴近研究问题的对比量

在同一患病样本、共享且匹配的区域掩膜上计算：

$$
Specificity_m=DL_{m,lesion}-DL_{m,nonlesion}.
$$

分别以健康叶片组织和背景作为 nonlesion 对照，避免混成一个结果。再计算：

$$
\Delta Specificity=Specificity_{improved}-Specificity_{baseline}.
$$

同时报告背景替换的平均绝对概率变化和类别翻转率。背景的有符号平均效应可能因正负抵消接近零，不能单独代表稳定。

预期证据是病斑特异性较高、背景敏感性较低、跨来源性能较好；**并不要求 improved 在所有 q 下都比 baseline 掉分更多**。病斑特征冗余、信息分布更广及原始置信度差异都可能改变删除曲线。

## 8. 指标与统计

### 8.1 分类与定位

- 原始及干预后：Accuracy、Balanced Accuracy、Macro-F1、各类 Recall；适用时报告 AUROC、PR-AUC。阈值由验证集固定。
- 归因定位：Top-k 病斑命中率 |M∩L|/|M|、病斑覆盖率 |M∩L|/|L|、IoU。
- 面积校正：病斑富集比 = Top-k 病斑命中率 / 病斑面积占候选区域比例。零病斑图像不计算该值，单独报告。
- 删除曲线：q 对目标类别概率、DL、Accuracy 等；概率删除曲线下面积较低通常意味着目标得分快速下降，但须结合原始得分、随机对照及伪影分析。
- 保留／插入实验作为补充验证充分性；不能仅凭一条曲线判断真实病斑依赖。

### 8.2 不确定性与复现

1. 所有效应优先做同图像配对比较；按叶片／植株／拍摄批次进行 cluster bootstrap，避免把同源图像当作独立样本。
2. 对 ATE、DL、Specificity 及跨模型差异报告 95% 置信区间；多种训练种子结果单独列出，避免把种子×图像全部当独立样本。
3. Random-k 每图建议至少 20 次抽样；LIME 和随机修复做多次重复，次数按计算预算预先固定。
4. 预先指定主要 q（例如 10%）与完整删除曲线汇总指标；其他 q 和方法比较作为次要分析，必要时控制多重比较。
5. 在验证集试运行估计方差，据预期效应和精度确定标注量；不预设“必然显著”。
6. 按类别、病斑面积、来源和原图正确／错误分层，检查总体平均是否掩盖某些群体的伪相关。

可增加模型参数随机化检查，确认热图对已训练参数有响应；该检查只是解释方法的基本质量控制。[Sanity Checks 原论文](https://proceedings.neurips.cc/paper/8160-sanity-checks-for-saliency-maps.pdf)。

## 9. 建议执行顺序

### 第一阶段：最小可行实验

1. 固定 baseline 与 improved 权重和独立测试集，复核分类性能与来源划分。
2. 建立分层抽样、独立病斑标注的评估子集。
3. 生成三种方法的原图热图，完成 Top-k 与病斑重叠统计。
4. 执行 Top-k、Random-k、Bottom-k，比较删除曲线。
5. 执行共享人工病斑、等面积健康组织和背景干预，计算配对 ATE、DL 和 Specificity。
6. 至少比较固定值遮挡与一种纹理替换／修复，完成编辑质量检查。

### 第二阶段：加强因果解释

7. 执行保持病斑的背景替换、多来源测试和归因掩膜交叉评估。
8. 增加病斑保留实验、边界敏感性分析与参数随机化检查。
9. 必要时增加 ROAR，单独解释其重训练结果。

若资源有限，优先保证独立病斑标注、区域匹配对照和第二种替换机制；增加热图数量本身不能替代这些证据。

## 11. 如何解读可能结果

| 观察结果 | 合理解释 |
|---|---|
| Top-k 删除掉分明显，但高贡献主要位于背景 | 模型依赖重要区域，但这些区域可能是伪相关 |
| 热图覆盖病斑，但删除病斑影响很小 | 定位与依赖证据不一致；检查冗余信息、编辑有效性及解释质量 |
| 删除病斑与删除等面积背景均大幅掉分 | 可能存在混合依赖或普遍编辑脆弱性，不能单独支持病斑特异性 |
| 只有黑块遮挡显著，修复／纹理替换无一致结果 | 结论对编辑机制敏感，可能受遮挡伪影影响 |
| 病斑特异性提高，背景变化更稳定，外部性能也改善 | 多项证据共同支持改进模型更依赖可迁移的病斑信息 |
| Top-k 小比例删除影响较小，但完整病斑删除影响明显 | 可能利用分散或冗余病斑特征，不能据此否定病斑学习 |

## 12. 论文／汇报可采用的研究表述

本研究不仅比较分类准确率，还联合归因定位、区域删除和背景干预，评估模型性能改进的特征来源。首先使用 LRP、Grad-CAM 和 LIME 定位支持目标类别预测的区域，并通过 Top-k 删除检验归因忠实性；随后利用独立病斑标注，在匹配编辑面积和替换机制的条件下，比较病斑、健康叶片组织及背景干预对固定模型输出的配对平均效应。最后通过保持病斑的背景替换和跨来源测试，检验模型对非病斑因素的敏感性。若改进模型表现出更高的病斑归因富集、更明确的病斑特异性和更稳定的背景响应，则支持其性能提升更多来自病斑相关信息，而非仅来自所测试的数据集伪相关。

结论适用于所评估的数据、干预机制和替代线索范围；“完全排除伪相关”需要更广泛的干预与外部验证。
