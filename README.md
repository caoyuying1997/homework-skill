

# 日常科研 Skill：植物病害分类与因果干预研究助手

面向植物病害图像分类、模型可解释性与反事实干预研究的可复用 Codex 技能。通过整理文献证据、设计受控实验、审查统计结果和组织科研汇报，帮助研究者建立从研究问题到实验结论的可复现证据链。

本技能以大豆健康叶片与靶斑病分类为主要研究背景，也可根据实际数据和任务调整至其他植物病害分类场景。病种、模型、数据规模及软件框架均以使用者提供的材料为准。

## 研究目标

分类准确率提高，并不意味着模型一定学到了真实病斑特征。模型还可能利用背景、光照、拍摄设备等与标签相关的线索。

本技能围绕以下问题开展工作：

- 改进模型的性能提升是否来自病斑相关信息？
- 模型归因的重要区域是否与真实病斑一致？
- 删除病斑是否比删除等面积健康组织或背景产生更大影响？
- 更换背景或数据来源后，模型预测是否保持稳定？
- 当前实验结果能够支持什么结论，还缺少哪些证据？

## 主要功能

### 1. 文献研读与方法迁移

从论文中提取研究问题、数据集、模型结构、干预策略、对照设计、评价指标及研究限制，并结合当前项目分析方法的适用条件。

交付内容可包括：

- 结构化论文阅读笔记；
- 多篇文献的方法对比；
- 可迁移到植物病害分类的实验思路；
- 原文证据与本项目建议的区分；
- 需要进一步核实的问题清单。

### 2. 分类实验设计与模型比较

协助设计 baseline 与改进模型的公平比较，检查数据划分、类别不平衡、训练预算和评价指标等设置。

重点关注：

- 按叶片、植株或采集批次划分数据，减少数据泄漏；
- 区分训练集、验证集和独立测试集的用途；
- 记录模型版本、随机种子与预处理配置；
- 联合分析分类性能、稳定性及跨来源泛化表现。

### 3. 模型归因与解释分析

支持围绕 LRP、Grad-CAM 和 LIME 设计归因评估方案，区分“模型关注哪里”与“模型是否真正依赖这些区域”。

可协助分析：

- 归因区域与人工病斑标注的重叠；
- Top-k、随机区域与低贡献区域的删除效应；
- 解释目标、归因粒度和实际遮挡面积；
- 两模型使用各自掩膜与共享掩膜时的比较差异。

### 4. 病斑反事实干预与对照设计

围绕病斑、健康叶片组织和背景构造受控编辑方案，检查预测变化是否具有病斑特异性。

可设计的实验包括：

- 病斑删除；
- 等面积健康组织和背景删除；
- 随机区域遮挡；
- 病斑保留与背景替换；
- 固定值遮挡、纹理替换或图像修复；
- 假编辑对照及编辑质量检查。

特别关注病斑残留、黄晕残留、接缝、色差和区域外变化，避免将编辑伪影误解为病斑信息的影响。

### 5. ATE 计算与结果审查

统一图像编辑效应的计算口径：

ATE = mean(p_edited - p_original)

删除损失 DL = -ATE

其中，原图与编辑图必须使用同一固定目标类别。概率差乘以 100 后表示百分点变化。

本技能可协助检查：

- ATE 正负号和单位是否一致；
- 病斑干预与非病斑对照是否匹配；
- 样本分母和分析总体是否明确；
- 汇总均值是否掩盖双向变化；
- 统计结果与文字结论是否一致；
- 是否需要配对比较、聚类置信区间或补充实验。

### 6. 组会汇报与科研写作

根据论文笔记和实验记录，组织研究问题、方法、结果、失败案例、研究限制及下一步计划。

可交付：

- 组会汇报提纲；
- 实验结果解读；
- 图表说明与结论措辞；
- 周度科研进展总结；
- 后续实验优先级建议。
